1. Introducción

¿Qué es T-CRUD?

T-CRUD es una librería para CodeIgniter 4 que permite crear CRUDs (Create, Read, Update, Delete) de forma virtual y basada en configuración. En lugar de generar archivos físicos para cada tabla, se define la configuración del CRUD en un controlador y la librería se encarga de todo lo demás.

Características principales

  • Listado con DataTables Server-Side (búsqueda, ordenamiento, paginación).
  • Filtros por columna con persistencia en sesión.
  • Formularios generados automáticamente según el tipo de campo.
  • 16 tipos de campo diferentes.
  • Relaciones 1 a N, N a N y dependientes.
  • Subida de archivos e imágenes con thumbnails.
  • Editor de texto enriquecido (Quill).
  • 16 callbacks para inyectar lógica personalizada.
  • Exportación a CSV, PDF e impresión.
  • Edición en línea.
  • Internacionalización (i18n).
  • Cacheo de configuración.
  • Soft deletes.

Requisitos

  • PHP 8.1 o superior.
  • CodeIgniter 4.3 o superior.
  • Composer.
  • Base de datos MySQL / MariaDB / PostgreSQL.
  • Bootstrap 5 (incluido en los assets).

2. Instalación

Instalación vía Composer

composer require tu-usuario/tcrud

Publicar assets y configuración

php spark tcrud:publish
php spark tcrud:config

Configurar rutas

Añade las rutas de T-CRUD en app/Config/Routes.php:

// Rutas para T-CRUD
$tcControllers = ['Books', 'Users'];

foreach ($tcControllers as $controller) {
    $path = strtolower(str_replace('\\', '/', $controller));
    
    $routes->get($path, "$controller::index");
    $routes->get("$path/tcadd", "$controller::index");
    $routes->post("$path/tcadd", "$controller::index");
    $routes->get("$path/tcedit/(:num)", "$controller::index");
    $routes->post("$path/tcedit/(:num)", "$controller::index");
    $routes->get("$path/tcdelete/(:num)", "$controller::index");
    $routes->get("$path/tcview/(:num)", "$controller::index");
    $routes->get("$path/tcclone/(:num)", "$controller::index");
    $routes->post("$path/tcclone/(:num)", "$controller::index");
    $routes->post("$path/tcbulkdelete", "$controller::index");
    $routes->post("$path/tcfilter", "$controller::index");
    $routes->post("$path/tcclearfilters", "$controller::index");
    $routes->post("$path/tcexportcsv", "$controller::index");
    $routes->post("$path/tcexportpdf", "$controller::index");
    $routes->post("$path/tcprint", "$controller::index");
    $routes->post("$path/tcinlineedit/(:num)", "$controller::index");
    $routes->post("$path/tcdependent", "$controller::index");
}

4. Uso básico

Crear un controlador

<?php

namespace App\Controllers;

use App\Libraries\TCrud\CrudBuilder;

class Books extends BaseController
{
    public function index()
    {
        $crud = new CrudBuilder();
        
        $crud->setTable('books')
             ->setSubject('Libro', 'Libros')
             ->columns(['id', 'title', 'author_id', 'price'])
             ->fields(['title', 'author_id', 'price', 'description'])
             ->displayAs([
                 'title' => 'Título',
                 'author_id' => 'Autor',
                 'price' => 'Precio'
             ])
             ->setRelation('author_id', 'authors', 'name')
             ->fieldType('description', 'textarea')
             ->fieldRequired(['title', 'author_id']);

        $output = $crud->render();

        if (isset($output->is_json) && $output->is_json) {
            return $this->response->setContentType('application/json')->setBody($output->output);
        }
        
        if ($output instanceof \CodeIgniter\HTTP\RedirectResponse) {
            return $output;
        }

        return view('layouts/admin', [
            'title'     => 'Gestión de Libros',
            'content'   => $output->output,
            'css_files' => $output->css_files ?? [],
            'js_files'  => $output->js_files ?? []
        ]);
    }
}

Configuración mínima

Los métodos mínimos para que un CRUD funcione son:

  • setTable() — la tabla de la base de datos.
  • setSubject() — el nombre singular y plural.
  • columns() — las columnas del listado.
  • fields() — los campos del formulario.

5. API: Métodos de configuración

setTable

public function setTable(string $table): self

Descripción: Define la tabla principal de la base de datos.

ParámetroTipoObligatorioDescripción
$tablestringSíNombre de la tabla en la BD

Retorna: $this (para encadenar)

$crud->setTable('books');

setPrimaryKey

public function setPrimaryKey(string $key): self

Descripción: Define la clave primaria de la tabla. Por defecto es id.

ParámetroTipoObligatorioDescripción
$keystringSíNombre de la clave primaria

Retorna: $this

$crud->setPrimaryKey('book_id');

setSubject

public function setSubject(string $singular, ?string $plural = null): self

Descripción: Define el nombre singular y plural de la entidad. Se usa en títulos y botones.

ParámetroTipoObligatorioDescripción
$singularstringSíNombre singular (ej. "Libro")
$plural?stringNoNombre plural. Si es null, se usa $singular . 's'

Retorna: $this

$crud->setSubject('Libro', 'Libros');

columns

public function columns(array $columns): self

Descripción: Define las columnas que se muestran en el listado. El orden del array es el orden de las columnas.

ParámetroTipoObligatorioDescripción
$columnsarraySíArray de nombres de columnas

Retorna: $this

$crud->columns(['id', 'title', 'author_id', 'price', 'status']);

fields

public function fields(array $fields): self

Descripción: Define los campos que se muestran en los formularios de add y edit.

ParámetroTipoObligatorioDescripción
$fieldsarraySíArray de nombres de campos

Retorna: $this

$crud->fields(['title', 'author_id', 'price', 'description']);

addFields

public function addFields(array $fields): self

Descripción: Define campos exclusivos para el formulario de add. Se suman a fields().

Retorna: $this

$crud->addFields(['password', 'confirm_password']);

editFields

public function editFields(array $fields): self

Descripción: Define campos exclusivos para el formulario de edit. Se suman a fields().

Retorna: $this

$crud->editFields(['last_login', 'updated_by']);

displayAs

public function displayAs(string|array $field, ?string $label = null): self

Descripción: Define etiquetas personalizadas para los campos. Acepta un string o un array asociativo.

ParámetroTipoObligatorioDescripción
$fieldstring|arraySíNombre del campo o array ['campo' => 'Etiqueta']
$label?stringNoEtiqueta si $field es string

Retorna: $this

// Individual
$crud->displayAs('title', 'Título');

// En bloque
$crud->displayAs([
    'title' => 'Título',
    'author_id' => 'Autor',
    'price' => 'Precio'
]);

where

public function where(string|array $field, ?string $operator = null, $value = null): self

Descripción: Añade condiciones al listado. Se combinan con AND.

ParámetroTipoObligatorioDescripción
$fieldstring|arraySíCampo o array ['campo' => 'valor']
$operator?stringNoOperador (=, >, <, etc.). Default: '='
$valuemixedNoValor a comparar

Retorna: $this

// Forma 1: campo = valor
$crud->where('status', 'published');

// Forma 2: campo operador valor
$crud->where('price', '>', 10);

// Forma 3: array de condiciones
$crud->where([
    'status' => 'published',
    'is_featured' => 1
]);

setValidationRules

public function setValidationRules(array $rules): self

Descripción: Define las reglas de validación de CI4 para los campos.

ParámetroTipoObligatorioDescripción
$rulesarraySíArray ['campo' => 'regla1|regla2']

Retorna: $this

$crud->setValidationRules([
    'title' => 'required|min_length[3]|max_length[255]',
    'email' => 'required|valid_email|is_unique[users.email,id,{id}]',
    'price' => 'required|numeric|greater_than[0]'
]);

setValidationRule

public function setValidationRule(string $field, string $rules): self

Descripción: Define la regla de validación de un solo campo.

Retorna: $this

$crud->setValidationRule('title', 'required|min_length[3]');

6. API: Métodos de campos

fieldType

public function fieldType(string $field, string $type, array $options = []): self

Descripción: Define el tipo de campo y sus opciones. Si el tipo es image o file, las opciones se guardan como configuración de subida. Si es dropdown, las opciones son el array de valores.

ParámetroTipoObligatorioDescripción
$fieldstringSíNombre del campo
$typestringSíTipo de campo (ver sección 12)
$optionsarrayNoOpciones del campo (depende del tipo)

Retorna: $this

Ejemplo con dropdown

$crud->fieldType('status', 'dropdown', [
    'draft' => 'Borrador',
    'published' => 'Publicado',
    'archived' => 'Archivado'
]);

Ejemplo con imagen

$crud->fieldType('cover_image', 'image', [
    'upload_path' => 'uploads/books/covers/',
    'max_size' => 2048,
    'allowed_types' => 'jpg|png|gif|webp',
    'thumbnail' => true,
    'thumbnail_size' => [150, 150]
]);

Ejemplo con archivo

$crud->fieldType('pdf_file', 'file', [
    'upload_path' => 'uploads/books/pdfs/',
    'max_size' => 5120,
    'allowed_types' => 'pdf|doc|docx'
]);

Opciones para image/file

OpciónTipoDefaultDescripción
upload_pathstring'uploads/'Ruta de subida (relativa a FCPATH)
max_sizeint2048Tamaño máximo en KB
allowed_typesstring—Extensiones permitidas separadas por |
thumbnailbooltrue (image)Generar thumbnail
thumbnail_sizearray[150, 150][ancho, alto] del thumbnail

fieldRequired

public function fieldRequired(string|array $fields): self

Descripción: Marca campos como requeridos. Añade la regla required de CI4 y muestra un asterisco rojo en el formulario.

ParámetroTipoObligatorioDescripción
$fieldsstring|arraySíCampo o array de campos

Retorna: $this

// Individual
$crud->fieldRequired('title');

// En bloque
$crud->fieldRequired(['title', 'author_id', 'price']);

fieldReadOnly

public function fieldReadOnly(string|array $fields): self

Descripción: Marca campos como de solo lectura. Se muestran pero no se pueden editar.

Retorna: $this

$crud->fieldReadOnly(['created_at', 'updated_at']);

fieldDisabled

public function fieldDisabled(string|array $fields): self

Descripción: Marca campos como deshabilitados. Se muestran grises pero no se envían en el POST.

Retorna: $this

$crud->fieldDisabled(['internal_code']);

setHidden

public function setHidden(string $field, $value = null, string $action = 'both'): self

Descripción: Oculta un campo en el formulario. Opcionalmente, fuerza un valor según la acción.

ParámetroTipoObligatorioDescripción
$fieldstringSíNombre del campo
$valuemixedNoValor forzado. Si es null, mantiene el valor del POST
$actionstringNo'add', 'edit', 'clone', 'both' (default), 'all'

Retorna: $this

// Ocultar solo en add, forzando 'draft'
$crud->setHidden('status', 'draft', 'add');

// Ocultar en edit, forzando el ID del usuario logueado
$crud->setHidden('updated_by', auth()->id(), 'edit');

// Ocultar en add y edit (default)
$crud->setHidden('tenant_id', 5);

// Ocultar en todas las acciones
$crud->setHidden('internal', null, 'all');

// Ocultar manteniendo el valor del POST
$crud->setHidden('code');

callbackColumn

public function callbackColumn(string $field, callable $callback): self

Descripción: Define una columna virtual. El callback recibe la fila y devuelve el valor a mostrar. La columna debe estar en columns().

ParámetroTipoObligatorioDescripción
$fieldstringSíNombre de la columna virtual
$callbackcallableSíFunción que recibe $row y devuelve string

Retorna: $this

// Precio con IVA
$crud->callbackColumn('price_with_tax', function($row) {
    return number_format($row->price * 1.21, 2) . ' €';
});

// Badge de estado
$crud->callbackColumn('status_badge', function($row) {
    $colors = ['draft' => 'secondary', 'published' => 'success', 'archived' => 'danger'];
    $color = $colors[$row->status] ?? 'secondary';
    return '' . ucfirst($row->status) . '';
});

setRelation

public function setRelation(string $field, string $relatedTable, string $displayField, ?string $orderBy = null, array|callable $where = []): self

Descripción: Define una relación 1 a N. El campo se muestra como un dropdown con los valores de la tabla relacionada.

ParámetroTipoObligatorioDescripción
$fieldstringSíCampo FK en la tabla principal
$relatedTablestringSíTabla relacionada
$displayFieldstringSíCampo a mostrar de la tabla relacionada
$orderBy?stringNoOrden (ej. 'name ASC')
$wherearray|callableNoCondiciones para filtrar las opciones

Retorna: $this

// Simple
$crud->setRelation('author_id', 'authors', 'name');

// Con orden y filtro
$crud->setRelation('category_id', 'categories', 'name', 'name ASC', ['is_active' => 1]);

setRelationNtoN

public function setRelationNtoN(string $field, string $pivotTable, string $relatedTable, string $pivotPrimaryField, string $pivotRelatedField, string $displayField, ?string $orderField = null): self

Descripción: Define una relación N a N con tabla pivote. Se muestra como un multiselect con TomSelect.

ParámetroTipoObligatorioDescripción
$fieldstringSíNombre del campo en el CRUD
$pivotTablestringSíTabla pivote
$relatedTablestringSíTabla relacionada
$pivotPrimaryFieldstringSíCampo pivote → tabla principal
$pivotRelatedFieldstringSíCampo pivote → tabla relacionada
$displayFieldstringSíCampo a mostrar de la tabla relacionada
$orderField?stringNoCampo de orden en la tabla pivote

Retorna: $this

$crud->setRelationNtoN(
    'authors',           // Campo en el CRUD
    'book_authors',      // Tabla pivote
    'authors',           // Tabla relacionada
    'book_id',           // FK pivote → books
    'author_id',         // FK pivote → authors
    'name',              // Campo a mostrar
    'sort_order'         // Campo de orden (opcional)
);

setDependentRelation

public function setDependentRelation(string $field, string $dependsOn, string $relatedTable, string $displayField, string $foreignKey, array $where = []): self

Descripción: Define una relación dependiente. El select del campo hijo se carga vía AJAX cuando cambia el campo padre.

ParámetroTipoObligatorioDescripción
$fieldstringSíCampo hijo
$dependsOnstringSíCampo padre del que depende
$relatedTablestringSíTabla relacionada
$displayFieldstringSíCampo a mostrar
$foreignKeystringSíFK en la tabla relacionada
$wherearrayNoCondiciones adicionales

Retorna: $this

// El campo padre debe tener setRelation
$crud->setRelation('country_id', 'countries', 'name');

// El campo hijo depende del padre
$crud->setDependentRelation(
    'city_id',          // Campo hijo
    'country_id',       // Depende de
    'cities',           // Tabla relacionada
    'name',             // Campo a mostrar
    'country_id',       // FK en cities
    ['is_active' => 1]  // Where opcional
);

7. API: Callbacks

T-CRUD ofrece 16 callbacks que se ejecutan en diferentes momentos del ciclo de vida. Todos devuelven $this para encadenar.

Callbacks de inserción

callbackBeforeInsert

public function callbackBeforeInsert(callable $callback): self

Descripción: Se ejecuta antes de insertar un registro. Recibe los datos y debe devolverlos modificados.

$crud->callbackBeforeInsert(function($data) {
    $data['created_at'] = date('Y-m-d H:i:s');
    $data['created_by'] = auth()->id();
    return $data;
});

callbackAfterInsert

public function callbackAfterInsert(callable $callback): self

Descripción: Se ejecuta después de insertar. Recibe los datos y el ID insertado.

$crud->callbackAfterInsert(function($data, $insertId) {
    log_message('info', "Registro insertado con ID: $insertId");
    // Enviar email, crear relación, etc.
});

Callbacks de actualización

callbackBeforeUpdate

public function callbackBeforeUpdate(callable $callback): self

Descripción: Se ejecuta antes de actualizar. Recibe los datos y el ID. Debe devolver los datos modificados.

$crud->callbackBeforeUpdate(function($data, $id) {
    $data['updated_at'] = date('Y-m-d H:i:s');
    $data['updated_by'] = auth()->id();
    return $data;
});

callbackAfterUpdate

public function callbackAfterUpdate(callable $callback): self

Descripción: Se ejecuta después de actualizar. Recibe los datos y el ID.

$crud->callbackAfterUpdate(function($data, $id) {
    log_message('info', "Registro actualizado: $id");
});

Callbacks de eliminación

callbackBeforeDelete

public function callbackBeforeDelete(callable $callback): self

Descripción: Se ejecuta antes de eliminar. Recibe el ID.

$crud->callbackBeforeDelete(function($id) {
    log_message('info', "Eliminando registro: $id");
});

callbackAfterDelete

public function callbackAfterDelete(callable $callback): self

Descripción: Se ejecuta después de eliminar. Recibe el ID.

$crud->callbackAfterDelete(function($id) {
    log_message('info', "Registro eliminado: $id");
});

Callbacks de archivos

callbackBeforeUpload

public function callbackBeforeUpload(callable $callback): self

Descripción: Se ejecuta antes de subir un archivo. Recibe el archivo y el campo. Puede devolver false para cancelar.

$crud->callbackBeforeUpload(function($file, $field) {
    // Validar o modificar el archivo
    if ($file->getSize() > 1000000) {
        return false; // Cancelar
    }
    return $file;
});

callbackAfterUpload

public function callbackAfterUpload(callable $callback): self

Descripción: Se ejecuta después de subir. Recibe la ruta y el campo.

$crud->callbackAfterUpload(function($path, $field) {
    log_message('info', "Archivo subido: $path en campo $field");
});

callbackBeforeDeleteFile

public function callbackBeforeDeleteFile(callable $callback): self

Descripción: Se ejecuta antes de eliminar un archivo. Recibe la ruta.

$crud->callbackBeforeDeleteFile(function($path) {
    log_message('info', "Eliminando archivo: $path");
});

callbackAfterDeleteFile

public function callbackAfterDeleteFile(callable $callback): self

Descripción: Se ejecuta después de eliminar un archivo. Recibe la ruta.

$crud->callbackAfterDeleteFile(function($path) {
    log_message('info', "Archivo eliminado: $path");
});

Callbacks de clonación

callbackBeforeClone

public function callbackBeforeClone(callable $callback): self

Descripción: Se ejecuta antes de clonar. Recibe los datos y debe devolverlos modificados.

$crud->callbackBeforeClone(function($data) {
    $data['title'] = $data['title'] . ' (copia)';
    return $data;
});

callbackAfterClone

public function callbackAfterClone(callable $callback): self

Descripción: Se ejecuta después de clonar. Recibe los datos y el nuevo ID.

$crud->callbackAfterClone(function($data, $newId) {
    log_message('info', "Registro clonado: $newId");
});

Callbacks de bulk delete

callbackBeforeBulkDelete

public function callbackBeforeBulkDelete(callable $callback): self

Descripción: Se ejecuta antes de eliminar varios registros. Recibe el array de IDs y debe devolverlo modificado.

$crud->callbackBeforeBulkDelete(function($ids) {
    // Filtrar IDs no permitidos
    return array_filter($ids, fn($id) => $id > 0);
});

callbackAfterBulkDelete

public function callbackAfterBulkDelete(callable $callback): self

Descripción: Se ejecuta después de eliminar varios registros. Recibe el array de IDs.

$crud->callbackAfterBulkDelete(function($ids) {
    log_message('info', count($ids) . ' registros eliminados');
});

Callbacks de N a N

callbackBeforeNtoN

public function callbackBeforeNtoN(callable $callback): self

Descripción: Se ejecuta antes de guardar las relaciones N a N. Recibe el campo, los IDs y el ID del registro. Debe devolver los IDs modificados.

$crud->callbackBeforeNtoN(function($field, $ids, $recordId) {
    // Filtrar IDs válidos
    return array_filter($ids, fn($id) => $id > 0);
});

callbackAfterNtoN

public function callbackAfterNtoN(callable $callback): self

Descripción: Se ejecuta después de guardar las relaciones N a N.

$crud->callbackAfterNtoN(function($field, $ids, $recordId) {
    log_message('info', "Relaciones guardadas: $field");
});

Callbacks de columnas (columnas virtuales)

Se definen con callbackColumn() (ver sección 6). Reciben la fila y devuelven el valor a mostrar.

$crud->callbackColumn('full_name', function($row) {
    return $row->first_name . ' ' . $row->last_name;
});

11. Tipos de campo

T-CRUD soporta los siguientes tipos de campo. Se configuran con fieldType($field, $type, $options).

text

Input de texto estándar.

$crud->fieldType('title', 'text');

Listado: Se muestra el valor tal cual.

Formulario: <input type="text">

Vista: Se muestra el valor escapado.

textarea

Área de texto multilínea.

$crud->fieldType('description', 'textarea');

Formulario: <textarea rows="4">

Vista: Se muestra con nl2br() para respetar los saltos de línea.

dropdown

Select con opciones predefinidas.

$crud->fieldType('status', 'dropdown', [
    'draft' => 'Borrador',
    'published' => 'Publicado',
    'archived' => 'Archivado'
]);

Listado: Se muestra la etiqueta (ej. "Borrador"), no el valor (ej. "draft").

Formulario: <select> con las opciones.

Vista: Se muestra la etiqueta.

date

Input de fecha.

$crud->fieldType('published_date', 'date');

Formulario: <input type="date">

Listado: Se muestra formateado como dd/mm/yyyy.

Vista: Se muestra formateado como dd/mm/yyyy.

time

Input de hora.

$crud->fieldType('opening_time', 'time');

Formulario: <input type="time">

Listado: Se muestra formateado como HH:MM.

Vista: Se muestra formateado como HH:MM.

datetime

Input de fecha y hora.

$crud->fieldType('published_at', 'datetime');

Formulario: <input type="datetime-local">

Listado: Se muestra formateado como dd/mm/yyyy HH:MM.

Vista: Se muestra formateado como dd/mm/yyyy HH:MM.

number

Input numérico.

$crud->fieldType('price', 'number');

Formulario: <input type="number" step="any">

email

Input de email con validación HTML5.

$crud->fieldType('email', 'email');

Formulario: <input type="email">

Listado: Se muestra como enlace mailto:.

Vista: Se muestra como enlace mailto:.

url

Input de URL con validación HTML5.

$crud->fieldType('website', 'url');

Formulario: <input type="url">

Listado: Se muestra como enlace externo.

Vista: Se muestra como enlace externo.

password

Input de contraseña.

$crud->fieldType('password', 'password');

Formulario: <input type="password"> con texto de ayuda "Dejar en blanco para no cambiar".

Listado: No se muestra (se excluye del listado).

Vista: No se muestra.

checkbox

Switch booleano (0/1).

$crud->fieldType('is_featured', 'checkbox');

Formulario: <input type="checkbox" role="switch">

Listado: Se muestra como badge "Sí" / "No".

Vista: Se muestra como badge "Sí" / "No".

Valor: Si no se marca, se guarda como 0. Si se marca, como 1.

color

Selector de color.

$crud->fieldType('brand_color', 'color');

Formulario: <input type="color">

Listado: Se muestra un cuadro de color + el código hexadecimal.

Vista: Se muestra un cuadro de color + el código hexadecimal.

Valor: Hexadecimal (#RRGGBB).

image

Subida de imagen con thumbnail.

$crud->fieldType('cover_image', 'image', [
    'upload_path' => 'uploads/books/covers/',
    'max_size' => 2048,
    'allowed_types' => 'jpg|png|gif|webp',
    'thumbnail' => true,
    'thumbnail_size' => [150, 150]
]);

Formulario: <input type="file" accept="image/*"> + previsualización del archivo actual + checkbox "Eliminar archivo actual".

Listado: Se muestra el thumbnail. Al hacer clic, se abre un modal con la imagen completa.

Vista: Se muestra la imagen con un enlace para verla en tamaño completo.

Valor en BD: Ruta relativa (ej. uploads/books/covers/abc123.jpg).

file

Subida de archivo genérico.

$crud->fieldType('pdf_file', 'file', [
    'upload_path' => 'uploads/books/pdfs/',
    'max_size' => 5120,
    'allowed_types' => 'pdf|doc|docx'
]);

Formulario: <input type="file"> + nombre del archivo actual + checkbox "Eliminar archivo actual".

Listado: Se muestra un icono según la extensión. Tooltip con el nombre. Al hacer clic, se abre en nueva pestaña.

Vista: Se muestra un botón de descarga.

Valor en BD: Ruta relativa.

wysiwyg

Editor de texto enriquecido (Quill).

$crud->fieldType('description', 'wysiwyg');

Formulario: Editor Quill con barra de herramientas (negritas, listas, enlaces, imágenes, etc.).

Listado: Se muestra un extracto del texto plano (sin HTML).

Vista: Se muestra el HTML renderizado.

Valor en BD: HTML sanitizado.

hidden

Campo oculto. Se configura con setHidden() (ver sección 6).

Formulario: No se muestra.

Listado: Solo se muestra si está en columns() y no está oculto en both/all.

class Books extends BaseController
{
    public function index()
    {
        $crud = new CrudBuilder();
        
        $crud->setTable('books')
             ->setSubject('Libro', 'Libros')
             ->columns(['id', 'title', 'author_id', 'price', 'status'])
             ->fields(['title', 'author_id', 'price', 'description', 'status'])
             ->displayAs([
                 'title' => 'Título',
                 'author_id' => 'Autor',
                 'price' => 'Precio',
                 'description' => 'Sinopsis',
                 'status' => 'Estado'
             ])
             ->setRelation('author_id', 'authors', 'name')
             ->fieldType('description', 'textarea')
             ->fieldType('status', 'dropdown', [
                 'draft' => 'Borrador',
                 'published' => 'Publicado',
                 'archived' => 'Archivado'
             ])
             ->fieldRequired(['title', 'author_id', 'price'])
             ->setValidationRules([
                 'title' => 'required|min_length[3]|max_length[255]',
                 'author_id' => 'required|integer|is_not_unique[authors.id]',
                 'price' => 'required|numeric|greater_than[0]'
             ]);

        return $this->renderCrud($crud, 'Gestión de Libros');
    }
    
    private function renderCrud($crud, $title)
    {
        $output = $crud->render();
        
        if (isset($output->is_json) && $output->is_json) {
            return $this->response->setContentType('application/json')->setBody($output->output);
        }
        
        if ($output instanceof \CodeIgniter\HTTP\RedirectResponse) {
            return $output;
        }
        
        return view('layouts/admin', [
            'title' => $title,
            'content' => $output->output,
            'css_files' => $output->css_files ?? [],
            'js_files' => $output->js_files ?? []
        ]);
    }
}

             ->fieldType('is_featured', 'checkbox')
             ->fieldType('published_date', 'date')
             ->fieldType('price', 'number')
             ->fieldType('pages', 'number')
             ->fieldType('cover_image', 'image', [
                 'upload_path' => 'uploads/books/covers/',

                 'allowed_types' => 'jpg|png|gif|webp',

                 'thumbnail_size' => [150, 150]
             ])
             ->fieldType('pdf_file', 'file', [
                 'upload_path' => 'uploads/books/pdfs/',
                 'max_size' => 5120,
                 'allowed_types' => 'pdf|doc|docx'
             ])
             // Validación

             ->setValidationRules([
                 'title' => 'required|min_length[3]|max_length[255]',

class Users extends BaseController

    public function index()
    {
        $crud = new CrudBuilder();

             ->setSubject('Usuario', 'Usuarios')
             ->columns(['id', 'username', 'email', 'roles', 'status', 'created_at'])
             ->fields(['username', 'email', 'password', 'roles', 'status'])
             ->addFields(['password', 'confirm_password'])
             ->editFields(['password'])
             ->displayAs([
                 'username' => 'Usuario',
                 'email' => 'Correo',
                 'password' => 'Contraseña',
                 'roles' => 'Roles',
                 'status' => 'Estado'
             ])
             ->setRelationNtoN(
                 'roles', 'user_roles', 'roles',
                 'user_id', 'role_id', 'name'
             )
             ->fieldType('password', 'password')
             ->fieldType('status', 'dropdown', [
                 'active' => 'Activo',
                 'inactive' => 'Inactivo',
                 'banned' => 'Baneado'
             ])
             ->fieldRequired(['username', 'email'])
             ->setValidationRules([
                 'username' => 'required|min_length[3]|is_unique[users.username,id,{id}]',
                 'email' => 'required|valid_email|is_unique[users.email,id,{id}]',
                 'password' => 'permit_empty|min_length[6]'
             ])
             ->callbackBeforeInsert(function($data) {
                 if (!empty($data['password'])) {
                     $data['password'] = password_hash($data['password'], PASSWORD_DEFAULT);
                 }
                 unset($data['confirm_password']);
                 $data['created_at'] = date('Y-m-d H:i:s');
                 return $data;
             })
             ->callbackBeforeUpdate(function($data, $id) {
                 if (!empty($data['password'])) {
                     $data['password'] = password_hash($data['password'], PASSWORD_DEFAULT);
                 } else {
                     unset($data['password']);
                 }
                 unset($data['confirm_password']);
                 $data['updated_at'] = date('Y-m-d H:i:s');
                 return $data;
             })
             ->clearOnClone(['username', 'email', 'password'])
             ->enableBulkDelete();

        return $this->renderCrud($crud, 'Gestión de Usuarios');
    }
}

Reglas de uso para IA

  1. Siempre llamar a render() al final.
  2. Siempre manejar los 3 tipos de salida: JSON, RedirectResponse y HTML.
  3. Los métodos fluidos devuelven $this, se pueden encadenar.
  4. Las rutas deben estar definidas en Routes.php (ver sección 2).
  5. El idioma se configura en TCrud.php.
  6. Los assets se publican con php spark tcrud:publish.
  7. La configuración se copia con php spark tcrud:config.
  8. Las relaciones N a N requieren tabla pivote con FK a ambas tablas.
  9. Las relaciones dependientes requieren que el padre tenga setRelation().
  10. Los callbacks que modifican datos deben devolver el dato modificado.
